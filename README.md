# 高雄市人本交通環境 WebGIS 資料平台

本專案為整合人行道實體普查鋪面、臺灣通用電子地圖七大分類 POI、近三年交通事故與最小統計區人口密度之互動式 WebGIS 平台。

## 🌟 功能特色
1. **全域圖資套疊與動態透明度調節**（人行道淨寬合規、12公尺道路評估、通用版 POI、近三年事故等）
2. **多邊形 / 矩形 / 圓形 手繪空間框選分析**
3. **步行路網生活圈（等時圈／等距圈）分析**
4. **四大人本交通面向評估與總分計算**（步行環境、交通安全、生活機能）
5. **GIS 距離與面積即時量測、雙坐標定位**
6. **高解析度評估成果圖 PNG 匯出下載**
